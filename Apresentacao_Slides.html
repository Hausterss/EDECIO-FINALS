Abordagem Prática: IA como Copiloto de Consulta

Em vez de pedir para a IA gerar um sistema inteiro de uma vez, montamos a estrutura base que aprendemos em aula e usamos o ChatGPT para resolver 3 pontos específicos:

Prompt #1

Modelagem no Prisma

"Me ajuda a montar o schema.prisma relacionando Clientes, Serviços, Profissionais e Agendamentos com data, horário, status e valor cobrado."

Resultado: Entregou os 4 models com as relações @relation prontas e onDelete: Cascade.

Prompt #2

Bloqueio de Horário Duplicado

"Na rota POST /api/agendamentos, como validar no Prisma para impedir que o mesmo profissional seja agendado duas vezes na mesma data e horário?"

Resultado: Criou a consulta com findFirst ignorando status CANCELADO e retornando erro 409.

Prompt #3

Autopreenchimento e Caixa

"No React, ao escolher um serviço no select, quero preencher o campo Valor Cobrado automaticamente com o preço daquele serviço e somar o caixa no dashboard."

Resultado: Gerou a função aoSelecionarServico e o cálculo com .reduce() na API.

const concluidos = agendamentos.filter(

  (a) => a.status === 'AGENDADO'
);

const faturamentoTotal = concluidos.reduce(

Preenchimento Automático de Preço (App.jsx)

// Ao escolher o serviço no select, puxa o preço da tabela
const aoSelecionarServico = (servicoId) => {
  const serv = servicos.find(
    (s) => s.id === Number(servicoId)
  );
  setFormAgendamento((prev) => ({
    ...prev,
    servicoId,
    valorCobrado: serv ? String(serv.preco) : ''
  }));
};

Isso evita erro de digitação da recepcionista, mas mantém o campo aberto caso o salão queira dar um desconto.

Atualização Rápida de Status (PATCH)

const alterarStatusAgendamento = async (id, novoStatus) => {
  const resp = await fetch(
    `${API_URL}/agendamentos/${id}/status`,
    {
      method: 'PATCH',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ status: novoStatus })
    }
  );
  if (resp.ok) carregarTudo();
};

Com um clique em "Concluir" ou "Cancelar", a agenda e os cards financeiros do topo atualizam em tempo real.

5. Testes: O que Funcionou vs. Problemas Encontrados

Slide 6 de 7

✅ O que funcionou bem de primeira

  • • Relacionamentos no Prisma: O uso do include trouxe o nome do cliente, do serviço e da profissional direto na listagem da agenda sem precisar fazer várias requisições.
  • • Validação de choque de horário: A regra sugerida pelo ChatGPT bloqueou agendamentos duplicados no mesmo horário para a mesma profissional logo no primeiro teste.
  • • Layout com Tailwind CSS: A divisão em cards de resumo e abas ficou limpa e fácil de usar.

⚠️ Problemas encontrados e como corrigimos

  • • Erro de Tipagem no Prisma (String vs Number):
    Os campos clienteId e preco vinham do formulário React como texto ("1", "120") e o Prisma dava erro esperando Int ou Float. Corrigimos convertendo com Number() no Back-end.
  • • Erro ao Excluir Serviço já Agendado (Foreign Key):
    Ao tentar apagar um serviço que já tinha agendamentos, o banco bloqueava com erro 500. Adicionamos um try/catch retornando um aviso claro na tela explicando o vínculo.
